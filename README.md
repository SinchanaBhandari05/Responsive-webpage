# Task 4 - Mobile-Friendly Website Using CSS Media Queries

## Objective
Convert an existing desktop-only webpage into a responsive and mobile-friendly website using CSS media queries.

## Technologies Used
- HTML
- CSS
- CSS Media Queries
- VS Code
- Google Chrome DevTools

## Features
- Responsive layout
- Mobile-friendly navigation
- Stacked columns on mobile
- Responsive images
- Responsive buttons
- No horizontal scrolling
- Tested using Chrome DevTools

## Media Query
The website uses a CSS media query for screens with a maximum width of 768px.

## Testing
The responsive design was tested using Chrome DevTools Device Toolbar.
